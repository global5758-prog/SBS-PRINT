# SB Print

Jembatan cetak struk thermal untuk SB Sejahtera — cara kerjanya seperti RawBT, tanpa tulisan promosi.

- **web/print/** — halaman SB Print (diunggah ke `sbsqu.com/print/`).
- **android/** — aplikasi Android. Layarnya adalah halaman yang sama dengan `web/print/`,
  ditambah cetak di latar belakang lewat alamat `sbprint:base64,...` (sama seperti `rawbt:base64,...`).
- Setiap perubahan otomatis membangun APK baru. Unduh versi terbaru:
  https://github.com/global5758-prog/SBS-PRINT/releases/latest/download/SBPrint.apk

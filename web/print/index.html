⚡ Cetak Cepat

Mode ringkas. Status printer tetap terlihat di atas. Ketuk status untuk menyambungkan printer.

🧾 Struk dari SB Sejahtera siap dicetak

Sambungkan printer, struk langsung tercetak.
👁️ Lihat isi struk

📲 Pasang di HP

Instal SB Print sebagai aplikasi di layar utama HP Android supaya bisa dibuka seperti aplikasi biasa (tanpa alamat browser). Printer yang sudah disambungkan di browser juga langsung dikenali di aplikasi, begitu pula sebaliknya.

📲 Aplikasi SB Print sudah terpasang

Mencetak dari browser ini tetap bisa. Kalau lebih suka tampilan aplikasi, buka di aplikasi SB Print (printer yang sama tetap dikenali).

🔌 Koneksi Printer DEFAULT

Belum terhubung
Jadikan SB Print printer default Struk dari SB Sejahtera langsung dicetak otomatis tanpa tekan tombol Cetak.
⚠️ Supaya printer tersambung otomatis seperti RawBT (tanpa memilih printer tiap kali membuka SB Print), aktifkan sekali di Chrome HP:
1. Ketik chrome://flags di kolom alamat Chrome
2. Ketik Web Bluetooth di kolom pencarian, cari Use the new permissions backend for Web Bluetooth
3. Ubah ke Enabled, lalu tekan Relaunch.
Tanpa ini, SB Print tetap bisa mencetak, tapi setiap kali halaman dibuka ulang perlu menekan "Sambungkan & Cetak" sekali.
Mode aplikasi Android aktif — mendukung semua printer Bluetooth (termasuk Bluetooth Classic/SPP). Printer disambungkan sekali lalu dijaga tetap tersambung (ada pemberitahuan "SB Print — terhubung"). Hanya kalau sambungan terputus, aplikasi mencoba menyambung lagi lalu meminta Anda menyambungkan. Pastikan printer sudah di-pairing lewat Pengaturan Bluetooth HP.
Printer BT Cina 58/80mm umumnya pakai Bluetooth Classic (SPP), yang tidak bisa diakses langsung oleh browser. Tombol Bluetooth di sini hanya berfungsi untuk printer yang mendukung BLE. Kalau tidak muncul di daftar / gagal konek, gunakan USB (jika printer punya kabel data), atau pasang aplikasi Android SB Print untuk dukungan penuh ke semua printer BT. Setelah tersambung sekali, browser akan mencoba menyambung otomatis ke printer yang sama tiap kali halaman dibuka.

Keluar dari SB Print?

Printer akan diputus supaya tidak menguras baterai. Printer tetap diingat — lain kali dibuka, SB Print menyambung lagi otomatis.

🔗 Integrasi dari SB Sejahtera

Halaman ini bisa dipanggil dengan parameter URL, contoh:
?data=BASE64_BODY&company=BASE64_NAMA&address=BASE64_ALAMAT&phone=BASE64_HP&qr=BASE64_QR&barcode=BASE64_BARCODE&autoprint=1&width=48

data: isi/badan struk (item, total, dll), Base64 UTF-8. Apit satu baris dengan ** untuk tebal.
company, address, phone: opsional — kalau dikirim, akan menimpa kolom Kop Struk & dicetak sesuai Pengaturan Format yang tersimpan di HP ini.
qr, barcode: opsional, Base64 — dicetak sebagai kode QR/barcode asli printer (tajam, bukan gambar).
autoprint: 1 untuk langsung cetak begitu printer tersambung (sama seperti sakelar "Jadikan SB Print printer default"). Kalau printer belum tersambung, muncul tombol besar "Sambungkan & Cetak".
return: opsional, alamat (bukan Base64) untuk tombol "Kembali ke SB Sejahtera" setelah cetak.
width: 32 atau 48.

Logo perusahaan diatur di kartu Kop Struk (tersimpan di HP ini, ikut tercetak di semua struk otomatis — tidak dikirim lewat URL).
